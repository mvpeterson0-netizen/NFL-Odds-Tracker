# Changelog

- 2026-10-20 · V1.0 · Baseline: pipeline, site, scheduled workflow (tag `V1.0`).
- 2026-10-20 · PR: game selector row · Board shows a row of the selected week's games; click one to show only that game's players. UI only.
- 2026-10-20 · PR: opponent defense rank · New "Opp D rank" column on the Board and player pages: how the opponent ranks (1 = fewest allowed) in that stat against that position, using only games before each game; current-season rank on hover. Computed from nflverse stats.
- 2026-10-20 · PR: game weather · Temperature, wind and precipitation for every game from Open-Meteo (free, no key): forecast until kickoff, observed values about 6 days after; domes labeled. New derived file data/weather.csv. A weather outage never fails the run.
- 2026-10-20 · PR: weather fix · Keep forecast requests inside Open-Meteo's 16-day range (one stadium's request was rejected).
- 2026-10-20 · PR: API key rotation · Supports up to 6 Odds API keys (ODDS_API_KEY, ODDS_API_KEY_2..6); each pull uses the first key with enough credits and falls back to the next if one is rejected. Pull log notes the key number, never the key.
- 2026-10-20 · PR: scheduled snapshot pulls · Extra Odds API pulls for line movement: Monday 8 AM CT (hourly until props are posted), Thursday 2 PM, Sunday 8 AM. Shown with a yellow Mon/Thu/Sun AM chip until the graded pre-game line (~3 h before kickoff) arrives, then as movement (Mon → Thu → Sun AM → Pre). Never graded; only uses credits not needed for pre-game pulls.
- 2026-10-20 · PR: merged game cells · Board shows each game once, in one cell spanning all of that game's rows; thicker line between games, thin line between players. UI only.
- 2026-10-20 · PR: pinned game info · Board table scrolls in its own box; column headers and the current game's info stay pinned while scrolling. UI only.
- 2026-10-20 · PR: weather labels + Guide tab · One-glance weather label per game (Nice, Rainy, Snowy, Windy, Freezing, Cold, Hot, combined with &; Dome). Triggers listed on a new Guide tab, generated from the same thresholds the labels use. UI only.
- 2026-10-20 · PR: chart projection + weather emojis · Player chart shows the pre-game line value, or the latest Mon/Thu/Sun AM snapshot (dashed, labeled) until it arrives, plus actual values; y-axis gridlines now sit on exact round numbers; page re-checks for new data every 5 min. Weather labels get emojis (☀️ 🌧️ ❄️ 💨); the "(roof?)" label is removed.
- 2026-10-20 · PR: Stix branding + headshots · App renamed Stix with the new logo (header, browser tab icon, iPhone home-screen icon). Player headshots on the Board and player pages (nflverse headshot links, served from NFL's image CDN). UI + one build field.
- 2026-10-20 · PR: iPhone layout · Phone-only Board (game header once per game, one card per player with stacked markets: LINE, AVG over starts, OPP rank, TREND) and phone player page (summary tiles, chart, line movement, game log, context). Separate mobile.js / mobile.css; desktop falls back automatically if the phone code fails. Trend/season-average rules on the Guide tab.
- 2026-10-20 · PR: compact player table · Desktop player table fits a laptop screen (12 compact columns): "@ NE"/"vs. TEN", weather "label · temp · wind · rain", Odds "−111 / −113", Book "DK · Mon"/"DK · Pre" (details on hover), N/A for no slot / not collected, "Snap · use", notes behind ⓘ, DNP reason on hover. Chart week-7 label no longer cut off.
- 2026-10-21 · PR: targets on phone · WR/TE/RB cards show targets (last game with team share, last-3 average, season average over starts); phone player page adds a targets summary and a Tgt column in the game log; "last game usage" now points at the last game played. Phone files only.
- 2026-10-21 · PR: Defense tab · New tab ranking all 32 defenses by what they allow per game in each market (QB/RB/WR/TE × stat), with market buttons across the top, reversible sort, games counted, and each defense's opponent this week. Updates automatically with each data build.
- 2026-10-21 · PR: Search tab · Type a thesis in plain English; a rule-based parser turns it into filter chips (shown, removable, assumptions and ignored words listed), and the engine lists this week's players who pass every filter, with each value checked. Closest misses shown when nothing matches. Built so an AI translator could produce the same filters later. search.js, isolated like mobile.js.
- 2026-10-21 · PR: lines in search results · Each search result shows this week's line for the markets named in the search (or all of the player's markets if none are named): graded pre-game line if captured, otherwise latest snapshot, with odds and book.
- 2026-10-21 · PR: auto-update site · Deploy stamps the code files with a version (hash of the site code) and writes version.txt; open pages check it every 5 minutes and when the app comes back to the foreground, and reload when a new version is live. Fixes phones showing old code after an update.
- 2026-10-21 · PR: Monday fill-in pulls · If fewer than 75% of a game's starters (QB1, RB1, WR1, WR2, TE1) have a Monday line, pull again every 12 hours until covered or the Thursday 2 PM snapshot. Snapshots now use each book's latest pull.
- 2026-10-21 · PR: Search "Clear all" · One button clears the search box and every filter and returns to the starting Search screen; phone layout gives the search box its own row.
- 2026-10-21 · PR: pre-kickoff sweeps · After the ~3 h pre-game pull, re-check each game ~60 and ~15 minutes before kickoff; if any starter (QB1, RB1, WR1, WR2, TE1) still has no line, pull again. The graded line stays each book's first pre-game capture; sweeps only fill in players who had none (shown as "N min pre").
- 2026-10-22 · PR: this week's pulls on the Log tab · Every pull this week (newest first) with type, status, time, lines, players, tracked coverage and credits; tap one to see every line it returned (by player, market, book, odds) and which tracked players had no line.
- 2026-10-22 · PR: sweeps cover backups · Pre-kickoff sweeps also re-check tracked backups who average 25%+ of offensive snaps (e.g. RB2 Roschon Johnson, 30%), and sweeps now only use credits not needed for the month's remaining pre-game pulls.
- 2026-10-22 · PR: Search sentence builder · Search is now built from dropdown rows (measure · stat · comparison · compare to), with OR rows inside a box and AND boxes; compare to a number, his current line, his season avg or his last-N avg (optionally a %); position/team/game filters; gap shown and sortable; typing fills the rows; state kept in the address.
- 2026-10-22 · PR: Defense tab shows who each defense faces · New "Facing" column lists the opponent's slotted players at the chosen position (e.g. SEA, QB pass yds → Patrick Mahomes) with their current line for that market; yellow chip = Mon / Thu / Sun AM snapshot until the pre-game line is captured.
